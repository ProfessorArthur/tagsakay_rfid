# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog and follows Semantic Versioning.

## [1.0.0] - 2026-04-20

### Added
- Initial public release of TagSakay RFID project components.
- Open-source metadata for public collaboration.

### Included Components
- Cloudflare Workers backend in backend-workers.
- Vue frontend dashboard in frontend.
- ESP32 firmware in TagSakay_Fixed_Complete and TagSakay_LED_Matrix.

### Security and Release Hygiene
- Environment and secret files remain ignored.
- Token placeholder and non-essential PDF artifacts excluded from tracking.
